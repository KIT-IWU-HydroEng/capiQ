# Citation and references

## Citing capiQ

If you use capiQ in your research, please cite it as described in [CITATION.cff](https://github.com/KIT-IWU-HydroEng/capiQ/blob/main/CITATION.cff) (GitHub shows a *Cite this repository* button on the repository page).

Each release is archived on Zenodo: [10.5281/zenodo.24505637](https://doi.org/10.5281/zenodo.24505637) always points to the latest version, and the Zenodo page lists the DOI of each version.
